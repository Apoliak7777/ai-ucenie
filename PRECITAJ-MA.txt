Nasadenie API na VPS (raz) — jeden príkaz
-----------------------------------------
Na serveri ako root (konzola u xTom alebo SSH):

  curl -fsSL https://raw.githubusercontent.com/Apoliak7777/ai-ucenie/main/server/instaluj.sh | bash

Pri prvom behu sa spýta na dve heslá (píšu sa naslepo): heslo schránky info@aiucenie.online
a heslo do /admin. Nainštaluje nginx + python + certbot, stiahne repo do /var/www/ai-ucenie,
spustí službu ai-ucenie (systemd), zapne vhost ai.apoliak.online a vydá certifikát.
Na konci vypíše HOTOVO. Ten istý príkaz = aktualizácia (heslá sa už nepýta).
Podrobnosti, log a zmena hesla: server/README.md.
Repo môže zostať public — heslá sú len na serveri v server/nastavenia.env (je v .gitignore).

Rezervácie vidíš na https://aiucenie.online/admin/: po zadaní hesla meno, mail, telefón, balík,
poznámka, kedy prišla; tlačidlo Zmazať uvoľní termín späť do ponuky. Stránka je mimo Googlu
(robots.txt + noindex).

Lokálne skúšanie (rovnaké rozloženie ako naostro): server/nastavenia.env podľa nastavenia.vzor,
python server/rezervacie.py (API na 8787) + python -m http.server 8791 (statika), otvoriť
http://127.0.0.1:8791/ — stránka aj /admin si API na 8787 nájdu samy.

Alternatívy (nepoužité): tá istá logika existuje aj ako Cloudflare Worker (worker/, lib/) a Pages
Functions (functions/); Alex Cloudflare odmietol, nechať tak.
Stará adresa ai.apoliak.online slúži teraz len ako adresa API (v DNS apoliak.online mieri na VPS).

Kde si upravíš termíny
----------------------
V index.html, na začiatku <script> úplne dole v súbore:

  PLAN        časy podľa dňa v týždni (1 = pondelok ... 6 = sobota, 0 = nedeľa)
              Po až Pi od 15:00, časy idú po 70 minútach = 60 min hodina + 10 min pauza
              (15:00, 16:10, 17:20, 18:30, 19:40). Víkend prázdny.
  OBSADENE    obsadené termíny vo formáte "2026-07-28 9:00"
  POCET_DNI   koľko dní s voľnými termínmi sa ponúkne
  MOJ_MAIL    kam chodia rezervácie

Odosielanie rezervácií
----------------------
Tam istá časť skriptu:

  API             adresa API na VPS (https://ai.apoliak.online); na 127.0.0.1 alebo localhoste
                  sa automaticky použije http://127.0.0.1:8787 (python server/rezervacie.py)
  ENDPOINT        API + "/api/rezervacia": rezervácia sa zapíše do databázy, termín ostane
                  obsadený pre všetkých, mne príde mail a klientovi potvrdenie. Prázdne = klientovi
                  sa otvorí jeho mail s vyplnenou rezerváciou (ak nemá mailový program, stratí sa).
  OBSADENE_URL    API + "/api/obsadene" — odtiaľ si widget pri načítaní stiahne obsadené termíny,
                  takže ich nevidí ani ďalší návštevník
  ENDPOINT_EXTRA  polia navyše, keby sa ENDPOINT nasmeroval na externú službu

Keď si termín medzitým vzal niekto iný, API vráti 409 a widget človeka vráti na výber
s hláškou — NEpresmeruje ho na mail.
Keď API neodpovedá vôbec, web ukáže chybu a otvorí mail ako záložnú cestu.
Formulár má aj skrytú pascu na roboty (pole "web") — ak ho niekto vyplní, rezervácia sa
neodošle (API to ticho zahodí tiež).
API prijíma dopyty len z aiucenie.online, www.aiucenie.online, apoliak7777.github.io
a z localhostu (CORS: POVOLENE_ORIGINY v server/rezervacie.py).

Termíny dohodnuté mimo stránky (telefón, mail) dopíš do OBSADENE v index.html, API o nich
nevie. POZOR: keby sa ENDPOINT niekedy presmeroval na cudziu službu, doplň ju do
ochrana-udajov.html do sekcie "Kde údaje sú" ako sprostredkovateľa.

Čo už je dorobené (nad rámec prvej verzie)
------------------------------------------
- výber balíka priamo v rezervácii (1 h / 2 h za sebou / 3 h / 6 h / tím)
- kontrola pri odoslaní, že vybraný termín medzitým neprešiel
- funguje aj bez JavaScriptu (obsah vidno, v rezervácii je mail a telefón)
- pripomienky v .ics súbore (deň vopred + hodinu pred hodinou)
- tieň na pravej hrane dní, aby bolo na mobile vidno, že sa dajú posúvať
- aria atribúty pre čítače obrazovky, 404 stránka, zjednotené farby
